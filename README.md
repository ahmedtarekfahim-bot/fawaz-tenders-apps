# FAWAZ Tenders Apps

برنامجين لويندوز لشركة فواز للتجارة والخدمات الهندسية، والاتنين بيتسطبوا من ملف Setup واحد:

| البرنامج | الـ exe | البورت | بيعمل إيه |
|---|---|---|---|
| **دليل مناقصات الخليج** | `FAWAZ Gulf Directory.exe` | 8766 | المطروح والقادم والمترسي في الكويت والسعودية والإمارات. بيتحدّث من النت كل 6 ساعات وبيتتبع التغييرات، وجنب كل نتيجة لينك الإعلان الرسمي. |
| **برنامج ترسيات CAPT** | `FAWAZ CAPT Awards.exe` | 8765 | ترسيات الجهاز المركزي من 2006 ومحاضر اجتماعاته. بيبحث بالعنوان أو الرقم، وبيعمل PDF واحد فيه قرار الترسية وصفحات المحاضر. |

البرنامجين بيشتغلوا كسيرفر محلي صغير، وبيفتحوا في المتصفح.

## التسطيب على أي جهاز
1. شغّل `FAWAZ Tenders Setup <الإصدار>.exe`. مش محتاج صلاحيات أدمن.
2. البرنامج بيتسطب في `%LOCALAPPDATA%\Programs\FAWAZ Tenders`، ومعاه:
   - اختصارات على سطح المكتب وقايمة ابدأ.
   - تشغيل الدليل مع ويندوز في الخلفية.
   - إدخال في "Installed apps" عشان تقدر تشيله من هناك.
3. أول تشغيل على جهاز جديد: الداتا بتتبني في `%LOCALAPPDATA%\FAWAZ Tenders\data`:
   - ملف الترسيات جاي جوه الـ Setup.
   - محاضر الجهاز من 2021 بتتنزل وتتفهرس لوحدها، وبتاخد وقت أول مرة.
   - محاضر 2018 لـ 2020 مش على موقع الجهاز. ممكن تنسخها في `data\CAPT MOM`.
4. على جهاز فواز الأساسي الداتا بتفضل زي ما هي في `D:\شغل فواز\11 - أرشيف العمل والهندسة\التسعير والعطاءات`.

**الإعدادات:** `%LOCALAPPDATA%\FAWAZ Tenders\settings.json`. فيها مكان الداتا، وفولدرات تقارير الجريدة وتقرير مشاريع، وكل كام ساعة يتحدّث. ممكن تخلي كذا جهاز يشتغلوا على فولدر مشترك.

## التحديث التلقائي
- **الداتا:** الدليل بيتحدّث كل 6 ساعات، والترسيات والمحاضر كل 3 أيام، طول ما البرنامج شغال.
- **البرنامج نفسه:** كل برنامج بيشيك على `updates/latest.json` في الـ GitHub repo. لو لقى إصدار أحدث بينزّل الـ Setup ويسطبه لوحده (`/S /restart`).

### إصدار نسخة جديدة
```
1. عدّل الكود في app\
2. زوّد الرقم في version.txt   (مثلاً 1.0.1)
3. python build.py
4. git add -A && git commit -m "v1.0.1" && git push
```
كل الأجهزة المتسطب عليها البرنامج هتاخد النسخة الجديدة في خلال ساعات.

## السورس
```
app\
  fawaz_config.py     مكان الداتا والإعدادات (نفس الجهاز أو جهاز جديد)
  updater.py          التحديث الذاتي من GitHub
  capt_tool.py        برنامج الترسيات: تحديث الإكسيل من capt.gov.kw، فهرس المحاضر، البحث، الـ PDF، السيرفر
  gulf_directory.py   الدليل: المصادر (capt / الجريدة / pahw / اعتماد / دبي eSupply / الأخبار)، المتابعة، السيرفر
  capt_app.py, gulf_app.py   نقطة البداية لكل exe
  ui\                 واجهات الـ HTML
installer\setup_main.py     الـ Setup والإزالة
build.py, build_config.json, version.txt
updates\            latest.json + FAWAZ-Tenders-Setup.exe  (دول اللي البرامج بتحمّلهم للتحديث)
```
البناء محتاج: `pip install pyinstaller pymupdf openpyxl pywin32 pillow`، وبعدين `python build.py`.

سطر الأوامر، من السورس أو من الـ exe:
```
python app\capt_app.py update | index | search "نص" | report "نص" | serve
python app\gulf_app.py update [--only KW,SA,AE] | search "نص" [--country SA] | report "نص" | --background
```
